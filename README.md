## 🚀 Features

- ✅ Add, delete, and mark tasks as complete
- ✏️ Edit tasks inline
- 🎨 Light and dark mode toggle
- 📱 Fully responsive for mobile and desktop
- 💾 LocalStorage support for saving tasks

---

## 🛠️ Tech Stack

- HTML5
- CSS3 / Tailwind CSS (optional)
- JavaScript (Vanilla or React)
